# Glok

휴대폰에서 직접 돌아가는 Glok 앱(안드로이드)입니다.

- 화면: `app/src/main/assets/Glok.html` (브라우저용 Glok.html과 같은 파일, 앱 안에서는 앱 모드로 동작)
- 엔진: llama.cpp (`app/src/main/cpp`, 서브모듈 고정 커밋 46ca246d). Gemma 4의 층별 임베딩 표(E2B에서 약 1.9GB)처럼 토큰마다 몇 줄만 쓰는 표는 파일에 둔 채 필요한 줄만 읽음
- 앱 전용 모델: Gemma 4 E2B 무검열(3.43GB). 브라우저 엔진은 2GB가 넘는 파일을 올리지 못해서 브라우저용 Glok.html에서는 목록에 나오지 않음
- 백그라운드: 모델이 올라가 있는 동안 포그라운드 서비스로 앱과 모델을 상시 유지(한 번 불러오면 다시 불러오지 않음, 안드로이드가 메모리 때문에 앱을 닫으면 서비스가 다시 떠서 모델을 먼저 올려 둠). 답변·그림·모델 다운로드 중에는 웨이크락으로 화면이 꺼져도 멈추지 않음
- 빌드: GitHub Actions(`.github/workflows/build.yml`)가 APK를 만들고 실제 모델로 엔진과 에뮬레이터 테스트를 돌린 뒤 릴리스에 올림
